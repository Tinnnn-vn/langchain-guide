# LangChain Từ Cơ Bản

Kho lưu trữ này ghi lại hành trình học tập và các thử nghiệm của tôi với LangChain.

### 1. Mô hình Chat (Chat Models)

- Mô hình Chat của OpenAI
- Thử nghiệm nhiều mô hình khác nhau
- Xử lý tin nhắn
- Cấu hình mô hình

### 2. Mẫu Prompt (Prompt Templates)

- Mẫu prompt cơ bản

### 3. Chuỗi (Chains)

- LCEL
- Chuỗi tuần tự (Sequential chains)
- Kết hợp chuỗi (Chain composition)
- Xử lý chuỗi song song (Chain parallel)
- Chuỗi điều kiện (Chain conditional)
